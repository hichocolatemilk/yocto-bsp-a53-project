# WSL 환경을 D 드라이브로 구축

## 1. 목표
Yocto 빌드 시 발생하는 대용량 저장 공간 문제를 해결하기 위해  
WSL 환경을 기본 C 드라이브가 아닌 D 드라이브로 이전

---

## 2. 수행 내용

### 1) WSL 설치 및 확인
```bash
wsl -l -o
wsl --install -d Ubuntu-22.04
wsl --set-default-version 2
```
### 2) WSL D드라이브로 옮기기
```bash
mkdir D:\wsl
wsl --exportUbuntu-22.04 D:\wsl\ubuntu22.tar
wsl --unregisterUbuntu-22.04
wsl --importUbuntu-22.04 D:\wsl\Ubuntu-22.04 D:\wsl\ubuntu22.tar--version2
```
